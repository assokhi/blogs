This blog is a flat folder of `.mdx` files. To publish a new post:

1. Add a file to `posts/your-slug.mdx`
2. Add frontmatter: `title`, `date`, `description`
3. Write the post in Markdown (or MDX, if you need components)
4. `git push`

GitHub Actions builds the site and publishes it to
[assokhi.github.io/blogs](https://assokhi.github.io/blogs/). No backend, no database —
just files.
